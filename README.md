# landing-assets-public

Landings de captación de los negocios de AOrueF, publicadas con GitHub Pages.

## Estructura

```
<Cliente>/<AAAAMMDD>_<Nombre>/
    index.html
    privacidad.html
    img/
    video/
```

- Una carpeta por cliente y una por landing, con el formato `AAAAMMDD_Nombre`.
- Sin espacios ni tildes en los nombres.
- Cada landing es autónoma: usa rutas relativas (`img/...`, `video/...`).
